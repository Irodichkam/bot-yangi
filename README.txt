Render uchun tayyorlangan Python Telegram Bot Loyihasi
=====================================================

Fayllar tarkibi:
- bot.py: Asosiy Telegram bot kodi (rasmlar va tugmalar bilan)
- requirements.txt: Render o'rnatadigan kutubxonalar (python-telegram-bot)
- render.yaml: Render platformasi uchun avtomatik sozlama

Render Sozlamalari:
- Build Command: pip install -r requirements.txt
- Start Command: python bot.py
